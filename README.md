📌 Project Overview

This project is a UI clone of the original website
🔗 https://www.fates.world/

The goal of this project was to practice and demonstrate advanced CSS layout and styling skills by recreating the visual design and structure of the original website using HTML, CSS, and JavaScript.

This project focuses purely on frontend UI implementation, replicating the layout, design elements, and responsiveness of the original site.

🛠 Technologies Used

HTML5 – Page structure

CSS3 – Styling, layout, and responsiveness

JavaScript – Interactive elements and UI behavior


✨ Features

Responsive website layout

Modern UI design inspired by the original site

Smooth scrolling and interactive UI behavior

Clean and organized CSS styling

Structured HTML layout for maintainability


🎯 Learning Objectives

Through this project, I practiced:

Advanced CSS layout techniques

Responsive design principles

UI replication from real-world websites

Structuring frontend projects effectively
